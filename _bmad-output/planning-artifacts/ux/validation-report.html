WaveAudit v2 — UX Design Validation Report

_bmad-output/planning-artifacts/ux/DESIGN.md · EXPERIENCE.md

Deux relectures externes (grille de cohérence des spines, accessibilité WCAG 2.1 AA) ont été intégrées dans DESIGN.md, EXPERIENCE.md et mockups/relecture.html. Tous les constats haute et moyenne des deux relectures sont corrigés, ainsi que les trois constats basses de la relecture grille et les deux de la relecture accessibilité. Les spines passent en status: final.

Le point le plus structurant était l'absence de table explicite sévérité CVSS → couleur : elle est posée dans DESIGN.md (faible → accent, moyenne → attention, élevée → danger sur fond doux, critique → danger plein), avec un token danger-doux nouveau. Côté accessibilité, deux tokens de couleur ont été recalculés (gris, accent) pour atteindre 4,5:1 AA, et le focus clavier repose désormais sur un token dédié (contour 2px + décalage 2px) plutôt que sur le seul changement de couleur de bordure.
